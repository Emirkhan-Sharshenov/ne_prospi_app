# Ролик для Reels / Shorts / TikTok

`ne-prospi-reel.mp4` — 1080×1920, 30 кадров в секунду, 37 секунд, со звуком.
Текст на русском и английском одновременно, поэтому ролик годится и для местной,
и для англоязычной аудитории.

## Как он собран

```bash
python promo/make_audio.py           # музыка и звуки -> promo/reel-audio.wav
python promo/make_reel.py            # картинка + сведение со звуком -> mp4
python promo/make_reel.py --preview  # девять опорных кадров в promo/preview
```

Сначала звук, потом видео: `make_reel.py` в конце сам подмешивает `reel-audio.wav`,
если файл лежит рядом. Нужен только Python с Pillow, numpy и imageio-ffmpeg. Кадры рисуются в двойном
разрешении и уменьшаются — так получаются гладкие края. Шрифты, цвета и иконка
берутся из самого приложения, поэтому ролик и магазин выглядят одинаково.

Чтобы поменять текст, ищите сцены в конце файла: `scene_hook`, `scene_reveal`,
`scene_steps`, `scene_alarm`, `scene_features`, `scene_cta`. Тайминги сцен —
в константах `T1…T6`.

## Раскадровка

| Время | Что на экране |
|---|---|
| 0–5 с | Ночная дорога. «Уснул в автобусе?» → «И проехал остановку.» |
| 5–10 с | Иконка, название, «Будильник на вашу остановку» |
| 10–20,6 с | Три шага: отметить точку, выбрать за сколько будить, заблокировать телефон |
| 20,6–26 с | Вспышка и звонящий будильник: «Пора выходить!», выключение удержанием |
| 26–32 с | Шесть возможностей карточками |
| 32–37 с | Ссылка и «Не проспи свою остановку» |

## Эффекты

- тряска камеры на трёх ударах: знакомство, будильник, финал;
- световой всполох по диагонали на каждом переходе между сценами;
- лёгкое «дыхание» кадра в такт музыке, 100 ударов в минуту;
- покачивание телефона, чтобы кадр не был мёртвым;
- вспышка в момент звонка будильника;
- зерно и затемнение к краям: убирают полосы на градиентах и держат взгляд в центре.

## Музыка и звуки

`make_audio.py` синтезирует дорожку с нуля — ничего чужого, поэтому публиковать
можно где угодно и претензий по правам не будет. Внутри: бочка, хлопок, хэт,
бас, подклад, колокольчики и шумовые подводки, ре минор, 100 ударов в минуту,
свой небольшой ревербератор. Громкость сведена к −14 dBFS — это то, к чему
приводят звук Instagram и TikTok, так что ролик не будет тише чужих.

Звуки совпадают с картинкой: метка падает на карту — щелчок, выбрали 500 метров —
тик, экран заблокировали — замок, на 20,6 секунде удар и колокольчики будильника.

Если для конкретной площадки нужнее трендовый трек — просто выключите звук ролика
в редакторе и наложите свой: картинка смонтирована так, что удары приходятся
на 5, 10, 20,6, 26 и 32 секунды.
